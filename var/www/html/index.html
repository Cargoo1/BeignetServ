Webserv debug site

Home page simple, lisible et facile à modifier.

Cette page sert de point d’entrée pour tester le serveur, valider les routes de valid.conf et garder une base HTML propre pour le debug.

Tester l'upload

Routes utiles

  • /new-page
  • /errors/404.html et /errors/50x.html

Ce que la page couvre

  • Page d'accueil claire pour les tests de lecture
  • Page dédiée à l'upload, sans logique complexe
  • Page de redirection cible pour vérifier le retour 301
  • Pages d'erreur simples pour vérifier le code HTTP affiché
Astuce: gardez ce fichier comme hub de debug, puis modifiez uniquement les blocs HTML nécessaires.
