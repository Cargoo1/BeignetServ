Cible de /old-page

Pourquoi elle existe

  • Permet de valider une redirection simple sans complexité de rendu.
  • Garde un contenu clair pour la lecture du comportement HTTP.
  • Évite toute ambiguïté sur le chemin cible.

Test rapide

  • Ouvrir /old-page.
  • Vérifier que le serveur renvoie bien un 301.
  • Confirmer l'arrivée sur cette page.
